# 🏛️ SDM PUBLIC SCHOOL - AI DESIGN SYSTEM & TECH STACK

This document serves as the ground truth for the AI (Antigravity) to maintain consistency across the Institutional Governance ecosystem.

## 🎨 DESIGN PHILOSOPHY
- **Aesthetic**: Ultra-Premium, Elite, SaaS-style.
- **Visual Language**: High-density data, Glassmorphism (Backdrop Blurs), and Smooth Micro-animations.
- **Branding**: "SDM Hub" / "Institutional Command". Avoid legacy "Campus" references.

## 🌈 COLOR PALETTE (PREMIUM)
- **Primary**: Indigo-600 (`#4f46e5`) - Used for active nodes, primary buttons, and branding.
- **Secondary**: Slate-900 (`#0f172a`) - Used for deep headers, sidebars, and strong typography.
- **Success**: Emerald-500 (`#10b981`) - Used for positive trends, present attendance, and clean states.
- **Warning**: Amber-500 (`#f59e0b`) - Used for top ranks, alerts, and pending status.
- **Danger**: Rose-600 (`#e11d48`) - Used for deletions, critical failures, and absence.
- **Background**: Slate-50 (`#f8fafc`) - Clean, airy backgrounds with subtle shadows.

## ✍️ TYPOGRAPHY
- **Primary Font**: `Inter` or `Outfit` (Sans-serif).
- **Heading Style**: `font-black`, `tracking-tighter`, often `italic` and `uppercase` for a powerful institutional feel.
- **Label Style**: `text-[10px]`, `font-black`, `uppercase`, `tracking-[3px]`, `text-slate-400`.

## 🛠️ TECHNOLOGY STACK
- **Framework**: Next.js 14+ (App Router).
- **UI Components**: **Shadcn UI** (Dialog, Table, Input, Button, Card, Skeleton).
- **Styling**: Tailwind CSS (Utility-first).
- **Icons**: **Lucide React** (Always use for consistency).
- **State/Data**: Tanstack Query (React Query) for API synchronization.
- **Feedback**: React Hot Toast (High-fidelity toasts).
- **Processing**: React-easy-crop for merit scholar portraits.

## 📏 COMPONENT STANDARDS
- **Modals**: Always use `Dialog` (Shadcn) for forms (Toppers, Homework, etc.).
- **Tables**: High-density, grouped rows, hover effects, and action buttons appearing on hover (`opacity-0 group-hover:opacity-100`).
- **Cards**: `rounded-[40px]` or `rounded-lgxl` for a soft, modern feel.
- **Inputs**: Sleek, border-slate-100, `focus:ring-indigo-50`, `bg-slate-50/50`.

## 🚀 OPERATIONAL RULES
1. **Zero-Data Fallback**: Metrics should NEVER show `0.0%` if data is missing. Fallback to "Total Enrollment" or "Total Faculty" counts.
2. **Strict Typing**: Use `!!()` casting for boolean attributes like `disabled` in TypeScript.
3. **Role Awareness**: Dashboard must adapt dynamically for `SUPER_ADMIN`, `PRINCIPAL`, and `TEACHER`.
